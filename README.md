## About The Project

**TechFest 2025** is a fully responsive college event landing page built with pure HTML, CSS, and JavaScript. It serves as an official event page for a college tech fest, featuring event details, a guest speakers section, a full event schedule, and a student registration form integrated with Formspree for real-time form submissions and email notifications.

The project demonstrates clean frontend development skills including semantic HTML structure, custom CSS styling, responsive layout, and JavaScript-powered form handling with live user feedback.

---

## Features

- **Hero Section** — Eye-catching header with event name and tagline
- **About Section** — Event description with date and venue details
- **Event Schedule** — Full day timeline with session timings
- **Guest Speakers** — Speaker cards with photo, name, and designation
- **Registration Form** — Live form with name, email, department, and year fields
- **Formspree Integration** — Form submissions sent directly to email via Formspree API
- **Thank You Message** — Instant inline success feedback after registration
- **Social Links** — Instagram, LinkedIn, and Twitter links in the footer
- **Fully Responsive** — Mobile-friendly layout using CSS

## Getting Started

No build tools or dependencies needed. Just open in a browser.

```bash
# 1. Clone the repository
git clone https://github.com/karthi2006-46/Event.git
cd Event

# 2. Open in browser
open index.html
```

Or simply double-click `index.html` to launch it in your default browser.

### To Connect Your Own Formspree

1. Go to [formspree.io](https://formspree.io) and create a free account
2. Create a new form and copy your unique endpoint
3. In `index.html`, replace the fetch URL:

```javascript
fetch("https://formspree.io/f/YOUR_FORM_ID", {
```
